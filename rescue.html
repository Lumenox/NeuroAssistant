Lecteur de secours — visites neuro

Lit les fichiers chiffrés sans l'application. Aucune connexion, aucune donnée envoyée, la clé n'est jamais enregistrée : fermer la page l'efface.

1. Clé

Collez la clé (base64), une par ligne. Format 1:AbC…= pour une clé destinée à un key_id précis, ou la clé seule pour tous. Les lignes commençant par # sont ignorées.

2. Dossier à lire

Choisissez un dossier de visite, un dossier patient, ou le dossier patients entier. Les fichiers sont lus sur place, rien n'est copié.

Vérifier ce lecteur avec les jeux de référence

Choisissez le dossier des jeux de référence (celui qui contient TEST_KEY.txt et les dossiers 01_normale, …). Le lecteur compare son résultat à celui attendu pour chaque cas.
